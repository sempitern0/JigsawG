# Example artwork

`383471.jpg` is referenced by `examples/configs/standard_puzzle.tres` and included for local demonstration. The source and redistribution permissions for that photograph **have not been independently verified**. Replace it with artwork you own or have permission to redistribute before packaging a public demo or game.

Add your own PNG, JPEG or WebP images to test portrait/landscape aspect ratios, transparent backgrounds, small textures and high-resolution artwork (200–2000 pieces). Without a source texture, JigsawG can generate a diagnostic checkerboard.
